# Troubleshooting Guide

## Common Issues & Solutions

### 1. Database Connection Issue
- **Symptom**: Error indicating active database connection unavailable.
- **Solution**: Ensure application directory has read/write permissions. Restart the application.

### 2. Locked Administrator Account
- **Symptom**: Account locked after 5 incorrect password attempts.
- **Solution**: Wait 15 minutes for lock duration to expire, or use Emergency Recovery Mode with key `HimmelAdmin2026!`.

### 3. Report Export Verification
- **Symptom**: Export buttons disabled or inactive.
- **Solution**: Ensure selected date range contains valid records and export destination path has write permissions.
