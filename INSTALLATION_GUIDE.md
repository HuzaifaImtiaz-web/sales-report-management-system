# Himmel Pharmaceutical Sales Management System — Installation Guide

## System Requirements
- **Operating System**: Windows 10 / 11 (64-bit)
- **RAM**: 4 GB minimum (8 GB recommended)
- **Disk Space**: 500 MB free storage space

---

## Installation Steps
1. Run the installer executable: `Himmel Sales Management Setup 1.0.0.exe`.
2. Follow the NSIS installation wizard prompts and select the target directory.
3. Launch **Himmel Sales Management System** from the desktop shortcut or Start Menu.
4. On initial startup, SQLite database schema and initial seed data will initialize automatically.
